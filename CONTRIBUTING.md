# Contributing

Thanks for your interest in minimi.

1. Fork the repository and create a branch: `git checkout -b feature/my-change`
2. Set up locally (see the Quick start in the README).
3. Make a small, focused change and add or update a test in `tests/`.
4. Run the tests: `pytest -q`
5. Open a pull request that explains what changed and why.

Please never include API keys or private data in commits, issues or screenshots.
